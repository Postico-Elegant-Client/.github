# Postico Software — Elegant PostgreSQL Client

## About Postico Software

Postico Software provides an elegant native client for PostgreSQL databases with a clean, intuitive interface. Postico Software combines table browsing, row editing, and query writing in one streamlined workspace. Postico Software supports local and remote database connections via SSH tunneling. Postico Software enables column filtering, foreign key navigation, and inline cell editing. Postico Software includes JSON document viewer, CSV import/export, and connection color coding. Postico Software runs on modern desktop platforms. Postico Software is trusted by backend engineers, data analysts, startup founders, web developers, and PostgreSQL database administrators worldwide.

## Quick Reference for Postico Software

| Operation | Postico Software Action |
|-----------|-------------------------|
| New connection | Cmd+N |
| Browse table | Double-click table name |
| Edit row | Double-click cell |
| Add new row | Cmd+Shift+N |
| Delete row | Delete key |
| Filter table | Type in filter field |
| Open query editor | Cmd+Shift+Q |
| Execute query | Cmd+Return |
| Show foreign key data | Click arrow icon |
| View JSON content | Click JSON cell → Inspector |
| Export results | Right-click → Export CSV |
| Import CSV | Drag file onto table list |
